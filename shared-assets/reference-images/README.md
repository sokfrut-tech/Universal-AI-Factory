# Shared reference images

Upload project reference images, logos, launcher icons, UI screenshots, diagrams, and visual examples here.

## Usage
- Keep original files unchanged where possible.
- Use descriptive filenames, preferably including project and date.
- Add a short note in the commit message describing the asset.
- Tell the assistant the filename or paste the direct GitHub file link when you want an asset reviewed.

This folder is shared across projects in the Universal AI Factory.
