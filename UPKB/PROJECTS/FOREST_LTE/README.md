# Forest LTE Connectivity

- Project ID: `FOREST_LTE`
- Repository: not confirmed
- Evidence status: REPORTED

## Goal
Reliable 4G connectivity deep in a forest, prioritizing reception stability and weather resistance over lowest price. 5G is out of scope.

## Reported constraints
- Bands of interest: B3, B38, B31 (450 MHz), B20 and B7.
- Existing antenna: VARIUS Forester MIMO 2x2; reception reportedly changes with weather.
- Current use: temporary shelter; later a compact transportable setup for a new forest home.
- Router should support external antennas, protect the modem/router from rain and snow, and support operator/SIM failover where technically available.

## Evidence gaps
No canonical repository, RF measurements, exact router/antenna configuration, operator signal logs or installation photos have been confirmed in this UPKB inventory. These details remain REPORTED, not measured.
