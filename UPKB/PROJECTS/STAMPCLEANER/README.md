# StampCleaner

Repository: https://github.com/sokfrut-tech/stamp-cleaner

## Verified README facts
Android + browser app for removing light paper backgrounds from stamp/signature photos and exporting transparent PNG. README says processing remains local on-device/browser. Known limitations include shadows, coloured paper, uneven lighting and pale ink.
