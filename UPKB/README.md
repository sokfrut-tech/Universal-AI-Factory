# Universal Project Knowledge Base (UPKB)

Единая индексируемая база контекста, документации, исследований, задач, контрольных точек и журналов для проектов Sokfrut Tech.

## Обязательное правило
Любой агент перед работой выполняет [AGENT_START_PROTOCOL](CORE/AGENT_START_PROTOCOL.md), после значимого этапа обновляет checkpoint, индекс и журнал.

## Структура
- `CORE/` — правила, протоколы, безопасность и восстановление.
- `INDEX/` — реестры проектов, документов, задач, исследований, окружений и checkpoint.
- `PROJECTS/<id>/` — состояние, решения, исследования и документация проекта.
- `JOURNAL/` — неизменяемые по смыслу записи операций.
- `ENVIRONMENTS/` — реестр локальных и удалённых стендов.
- `SCHEMA/` — машинные схемы записей.
- `tools/` — индексатор и проверки (будут добавляться отдельными проверяемыми этапами).

## Источники истины
Исходный код и артефакты остаются в своих репозиториях. UPKB хранит проверяемые ссылки, метаданные, краткие выдержки, зависимости и точки продолжения. MEM 8495 — локальный быстрый контекст/указатель, но не единственное долговременное хранилище.

## Статусы достоверности
- `VERIFIED` — подтверждено доступным первичным источником/проверкой.
- `REPORTED` — сообщено пользователем или агентом, не перепроверено.
- `PLANNED` — запланировано, не реализовано.
- `UNKNOWN` — данных недостаточно.

Не повышать статус без доказательства. Не хранить секреты, токены и персональные данные.

## Текущий этап
Bootstrap: создана начальная структура и первичный реестр. Инвентаризация содержимого всех репозиториев, автоматический индексатор, CI-проверки и агентные интеграции — последующие задачи, пока не считать готовыми.
