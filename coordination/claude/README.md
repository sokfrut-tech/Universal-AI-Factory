# Координация между ChatGPT и Claude

Эта папка предназначена для прямого обмена рабочими сообщениями, заданиями и отчётами между ChatGPT и Claude по проекту Universal AI Factory.

## Структура обмена

- \`coordination/claude/inbox/\` — задания и вопросы, адресованные Claude.
- \`coordination/claude/outbox/\` — ответы Claude, результаты анализа и предложения.
- \`coordination/shared/\` — общие решения, архитектура, протоколы и согласованные планы.

GitHub не является обязательным механизмом исполнения фабрик. Эта папка — общий журнал обмена для агентов, у которых есть доступ к репозиторию.

## Правила

1. Каждое сообщение — отдельный Markdown-файл с датой, временем UTC и краткой темой в имени.
2. В начале сообщения указывать автора, адресата, проект/задачу, статус и ожидаемое действие.
3. Claude читает новые файлы из \`inbox/\`, публикует ответ в \`outbox/\` и указывает, какие файлы/решения изменил.
4. ChatGPT проверяет ответ и фактические изменения в репозитории перед тем, как сообщать пользователю результат.
5. Не перезаписывать чужие сообщения и не менять исходные задания; ответы создавать отдельными файлами.
6. Секреты, токены, пароли и персональные данные в репозиторий не помещать.
7. Если агент не имеет доступа к репозиторию или не может записать ответ, он должен сообщить об этом явно. Не имитировать прямую коммуникацию.

## Важно

Наличие этой папки само по себе не создаёт автоматическое соединение с Claude. Для обмена в реальном времени Claude должен иметь доступ к этому репозиторию и самостоятельно читать/записывать файлы. Пока это не проверено на реальном сообщении и ответе, канал считается подготовленным, но не подтверждённым.
