- Связанные файлы: docs/memory/russsearchoppo/MEMORY.md, app/src/main/java/ru/russsearch/oppo/translation/SpeechLanguagePicker.kt

## Контекст
Джарвис переводит речь с китайского и английского. Сейчас распознавание идёт маленькой моделью Vosk (42 МБ), у неё высокий процент ошибок на китайском (23,5% / 38,3% / 17,2% по тестам). Whisper (whisper.cpp, MIT) точнее и сам определяет язык. Нужен для режима перевода видео.

## Что требуется
1. Модель Whisper multilingual: ggml-small.bin (около 466 МиБ, 487 601 967 байт). Решение владельца принято: small. SHA-256 из зеркала LFS 1be3a9b2…987b, на HuggingFace не сверено: проверить.
2. Загрузка модели только по HTTPS с проверкой SHA-256, по образцу TranslationModelStore.
3. Нативная часть: whisper.cpp (исходники с лицензией MIT, с сохранением уведомления), CMake, JNI-мост. Сборка через NDK.
4. Класс WhisperRecognizer: загрузка модели, распознавание готового звука (16 кГц, моно), язык определяется автоматически, результат с метками времени.
5. Голосовой режим (живая речь) не переводить на Whisper без отдельного решения.

## Критерии результата
- Сборка зелёная на GitHub Actions, NDK установлен в workflow.
- Размер APK до и после, в отчёте.
- Проверка безопасности нативного кода по стандарту фабрики: Gitleaks, аудит зависимостей, CodeQL (если поддерживается), проверка лицензии whisper.cpp и модели.
- Секреты, ключи и токены в репозиторий не попадают.

Код в проекте: CMake/JNI (app/src/main/cpp), WhisperNative.kt, translation/WhisperRecognizer.kt, установка модели в TranslationModelStore. Голос на экране шара подключён в 2 коммите (run 41579051009).
