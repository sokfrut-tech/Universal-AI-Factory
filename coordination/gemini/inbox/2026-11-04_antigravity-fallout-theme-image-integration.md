## Контекст и решения пользователя

Пользователь одобрил Fallout / Wasteland направление оформления (“Очень нравится”) и попросил сделать красивую полноценную тему: фон, панели, кнопки и карточки в эстетике Fallout/Pip-Boy. Google Play публикация не планируется; нужен APK для прямой установки на телефон.

Пользователь сообщил, что поместил референс темы в общую папку обмена. Это не временная свалка: папка shared-assets/reference-images предназначена для долговременного обмена референсными изображениями между проектами и агентами.

## Подтверждённая текущая проблема

PR #13 “Give Antigravity Mobile a Fallout-inspired wasteland theme” слит в main (merge commit af19200fde861e74afd242114c217687f0266c22). Он изменил только палитру, градиент и декоративные HUD-круги в MainActivity.kt. Полноценный bitmap-фон/референс в Android resources не добавлен. Поэтому установленное приложение визуально почти не соответствует одобренному референсу.

Последний известный успешный build run: 41810107399 на main SHA af19200fde861e74afd242114c217687f0266c22. Он подтверждает сборку и CI UI tests, но не подтверждает соответствие референсу и не проверяет реальное устройство.

## Задача

1. Сверь оба shared reference images с текущим Android UI и предыдущим одобренным Fallout направлением.
2. Подготовь цельный визуальный дизайн на основе референса: настоящий фоновый арт/изображение, полупрозрачные HUD-панели, контрастные карточки, тематические кнопки/табы/индикаторы, аккуратная типографика и текстуры. Не ограничивайся заменой цветов.
3. Добавь выбранный фон в app/src/main/res/drawable-nodpi/ или подходящий ресурсный каталог. Не загружай изображение из сети во время работы приложения; фон должен входить в APK.
4. Учитывай читаемость текста поверх изображения, затемнение/градиент подложки, разные размеры экранов и Android 7+.
5. Сохрани без регрессий локальное сохранение задач, переходы статусов, Factory API URL/token settings, защищённое хранение токена, отправку задач и реальные progress polling. Не показывай фиктивные статусы/проценты.
6. Подготовь отдельную ветку и PR в Antigravity-Mobile. Не сливай PR самостоятельно.
7. Добавь/обнови Compose UI tests для наличия ключевых элементов и читаемости/состояний. Приложи emulator screenshots, если реальный CI emulator screenshot workflow доступен; не заявляй реальную проверку телефона.
8. Дай точный отчёт в coordination/gemini/outbox со ссылкой на этот файл, correlation ID, выбранным изображением, веткой/PR/commit, файлами, CI run и artifact URL, проверками и ограничениями.

## Критерии приёмки

- Выбранный референс реально используется в Android UI, а не просто хранится в репозитории.
- Полноценный Fallout/Wasteland визуальный стиль виден на главном экране и карточках.
- Существующая функциональность сохранена.
- Сборка и относящиеся к изменению тесты реально прошли.
- Есть отдельный PR; без самостоятельного merge.
- В отчёте явно указано, что не проверено.
