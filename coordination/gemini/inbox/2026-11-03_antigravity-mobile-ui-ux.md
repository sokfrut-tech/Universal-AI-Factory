## Контекст

Пользователь поручил поручить Gemini помощь именно с интерфейсом: «интерфейсом Gemini поможет, у него хорошо интерфейс рисовать получается».

В Antigravity Mobile уже есть Android-приложение с настройками подключения к Factory API, локальными задачами и отправкой задачи на сервер. API scaffold создан, но Worker пока не развернут, provider execution намеренно отключён. Не проектируй интерфейс так, будто исполнение моделей уже работает.

## Задача

1. Изучи актуальную ветку `main` и существующий UI Android-приложения. Сначала прочитай README и AGENTS.md (если есть), затем Kotlin/Compose экраны, тему, навигацию и тесты.
2. Предложи цельный, современный, аккуратный интерфейс мобильной панели управления AI Factory. Приоритет: понятность для нетехнического пользователя, хорошая визуальная иерархия, удобство на узком Android-экране, русский язык.
3. Обязательно продумай состояния:
   - главная панель: состояние подключения, активные/ожидающие/завершённые задачи;
   - создание задачи: цель, описание, выбор роли/агента (только реально реализованные варианты);
   - карточка задачи: этапы, статус, история событий, ошибки и следующий шаг;
   - настройки сервера: URL, токен (не показывать секрет повторно), проверка соединения;
   - честные заглушки/disabled состояния для функций, которые backend пока не поддерживает.
4. Подготовь конкретный визуальный результат: экраны/макеты плюс описание дизайн-системы (цвета, типографика, отступы, компоненты, иконки, состояния).
5. Если можешь работать непосредственно в репозитории — создай отдельную ветку и PR с UI-изменениями. Не меняй API, безопасность, архитектуру хранения или чужие ветки. Если прямой код недоступен, приложи точные макеты и спецификацию компонентов.
6. Не добавляй фиктивные показатели, не показывай «агент работает» без реального статуса, не имитируй успешное выполнение. Ошибки и ограничения должны быть понятны пользователю.
7. Проверь адаптивность и доступность: touch targets, контраст, масштабирование шрифта, длинные русские строки, loading/empty/error/offline состояния.
