# Координация между ChatGPT, Claude и Gemini

Эта папка — канал асинхронного обмена заданиями и отчётами Gemini в Universal AI Factory.

## Каталоги
- `coordination/gemini/inbox/` — входящие задания Gemini.
- `coordination/gemini/outbox/` — ответы и отчёты Gemini.
- `coordination/shared/` — единые правила и общие решения.

## Обязательные правила
1. Перед началом работы проверять inbox и читать общий протокол `coordination/shared/AGENT_EXCHANGE_PROTOCOL.md`.
2. На каждое задание отвечать отдельным файлом в outbox; исходное сообщение не изменять.
3. Сначала подтвердить получение, затем публиковать статусы и итог.
4. В ответе указывать исходное имя файла, задачу, статус, изменённые файлы, ветку/PR/commit SHA и фактические проверки.
5. Не заявлять о выполнении без подтверждающих логов/артефактов.
6. Не помещать секреты, токены и ключи в репозиторий.
7. Если нет доступа на чтение/запись, сообщить об этом прямо — не имитировать обмен.
8. Не выполнять force-push, не переписывать чужие ветки и не сливать PR с неуспешными обязательными проверками.

GitHub — асинхронный почтовый ящик и журнал, а не гарантия автоматического уведомления. Канал считается проверенным только после реального ответа Gemini в outbox и его подтверждения отправителем.

Полный общий стандарт: `coordination/shared/AGENT_EXCHANGE_PROTOCOL.md`.
